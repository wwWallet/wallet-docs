# Adding a Secondary Passkey

Adding another passkey gives you an additional way to access your wwWallet account. You can add a passkey on the current device, on a nearby device or on a physical security key.

## Steps to Add a Secondary Passkey

1. Open your wwWallet app or visit [demo.wwwallet.org](https://demo.wwwallet.org), then sign in to your account.

2. Go to **Settings** and select the **Account** tab.

3. In **Manage Passkeys**, select **Add passkey**.

4. Select **This device**, **Security key**, or **Nearby device**, depending on where you want to create the passkey. Follow your browser or device prompts to create it.

5. Enter a name that will help you recognize the passkey, then select **Save**.

6. When wwWallet asks you to authenticate once more, select **Continue** and use the new passkey. The new passkey appears in the **Manage Passkeys** list when setup is complete.

> **Note**: Make sure you can access the new passkey before relying on it as an alternative way to sign in.
