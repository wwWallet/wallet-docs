# Contributing

Thank you for your interest in contributing to wwWallet. Whether you’re improving the code, refining the documentation, reporting an issue or sharing an idea, your contribution helps make the project better for everyone.

## Code of Conduct

We want the wwWallet community to be welcoming, respectful and inclusive. Be considerate in your interactions, accept constructive feedback and help maintain a harassment-free environment.

Read the [wwWallet Code of Conduct](https://github.com/wwWallet/.github/blob/main/CODE_OF_CONDUCT.md) for the full expectations and reporting process.

## Contribution guidelines

Contributions generally start with an issue and are submitted through a pull request. Keep changes focused, follow the project’s development and pull request practices, and be ready to address feedback during review.

Read the full [Contribution Guidelines](https://github.com/wwWallet/.github/blob/main/CONTRIBUTING.md) before getting started.

## Questions or feedback?

If you have questions or want to share ideas, feel free to join the conversation in our [GitHub Discussions](https://github.com/orgs/wwWallet/discussions) or reach out through appropriate channels.
